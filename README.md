# lypa-lounge

Мінімальний фронтенд-проєкт для сервісу **Lipa Lounge** (M0 — Project Foundation).

## Технології

- React
- TypeScript (strict mode)
- Vite
- Plain CSS
- ESLint

## Скрипти

- `npm run dev` — запуск локального dev-сервера
- `npm run build` — production-збірка
- `npm run lint` — перевірка ESLint
